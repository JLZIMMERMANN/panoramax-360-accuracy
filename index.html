Zones de vigilance

Export

Génère corrections_exiftool.csv (photos gardées : position corrigée + cap). À copier dans le dossier des photos, puis : exiftool -csv=corrections_exiftool.csv . (ExifTool garde une copie *_original ; ajoutez -overwrite_original pour ne pas la garder).

Écrire dans les photos (Chrome / Edge)

Traçabilité du calage (EXIF)

Champ GPSAreaInformation (« reposition/1 » + JSON en anglais : orig, state, method, anchor.theme, changeset, timestamp ISO 8601, hist) et GPSProcessingMethod = MANUAL. Ces champs restent lisibles par ExifTool et visibles via l'API Panoramax.

Session de calage

La session (ancres, exclusions, clusters, photos examinées, réglages) est aussi enregistrée automatiquement : fichier calage_session.json dans le dossier (Chrome / Edge) et mémoire du navigateur. Elle vous est proposée à la réouverture de la même source.

Écriture directe dans les photos (Chrome / Edge)

Choisissez ensuite le dossier des photos : seul le bloc GPS de l'EXIF est modifié, l'image, le XMP 360° et le reste sont copiés tels quels.
